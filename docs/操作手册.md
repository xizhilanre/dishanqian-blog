# 📘 操作手册

个人博客站点，基于 [Astro](https://astro.build/) + AstroPaper 主题构建的纯静态站。
内容围绕 **AI、Agent、AI 产品、软件开发、技术学习、随笔** 展开。

> 日常维护只需要两件事：**写 Markdown** 和 **改一个配置文件**。
> 不需要数据库、后端服务或任何外部依赖。

---

## 📚 如何创建一篇文章

1. 在 `src/content/posts/` 下新建一个 `.md` 文件（文件名会成为文章 URL，例如 `my-post.md` → `/posts/my-post`）。
2. 在文件顶部写 frontmatter，必填字段如下：

```yaml
---
title: "文章标题"            # 必填
pubDatetime: 2026-10-02T10:00:00.000Z   # 必填，发布日期（未来时间=定时发布，会先隐藏）
description: "一句话摘要，用于首页卡片 / 搜索 / SEO"   # 必填
tags:                        # 可选，默认 ["others"]
  - AI
  - 随笔
featured: true               # 可选：true 时置顶为“精选”，出现在首页最前
draft: true                  # 可选：true 时在正式构建里不发布
modDatetime: 2026-10-03T09:00:00.000Z   # 可选：最后修改时间，会排在列表更前
canonicalURL: ""             # 可选：指定原文链接（转载场景）
ogImage: ""                  # 可选：这篇单独用一张分享图
---
```

3. 正文用标准 Markdown 写即可，支持代码块、表格、图片、引用等。
   想加目录，在正文写一行 `## Table of contents`。
4. 文件开头的 `_` 目录会被忽略（`_` 开头的文件/目录不会发布），可放草稿素材。

参考现有示例：`src/content/posts/ai-agents.md`。

## 🚀 本地预览

```bash
pnpm install       # 首次运行
pnpm dev           # 开发预览 http://localhost:4321
```

> 搜索（Pagefind）需要先跑一次完整构建才会索引，开发模式是实时内容、不含搜索索引。
> 想本地看到完整搜索效果：`pnpm build && pnpm preview`。

---

## 📦 完整构建与检查

```bash
pnpm build         # 类型检查 + 静态构建 + 生成搜索索引
pnpm check         # 只做类型检查
pnpm lint          # ESLint
pnpm preview       # 预览构建产物（dist/）
```

构建产物在 `dist/`，全部是静态文件（HTML / CSS / JS / 页面数据），可直接托管。

---

## 🌍 正式部署

1. 先把 `astro-paper.config.ts` 里的 `site.url` 改成你的正式域名。
2. 执行 `pnpm build`，得到 `dist/`。
3. 把 `dist/` 部署到任意静态托管即可，无需服务器：
   - **Cloudflare Pages / Vercel / Netlify**：构建命令 `pnpm build`，输出目录 `dist`。
   - **GitHub Pages**：见仓库 Actions 或手动上传 `dist/`。
4. 部署后在搜索引擎后台可提交你的 `sitemap-index.xml` 和 `rss.xml`。

## ⚙️ 全部配置集中在一个文件

所有需要你改的东西都在 **根目录 `astro-paper.config.ts`**：

| 配置 | 说明 |
| --- | --- |
| `site.url` | 正式域名，canonical / sitemap / RSS 都由它生成 |
| `site.title` / `site.description` | 博客名称与站点描述（SEO） |
| `site.author` | 作者名，文章默认作者 |
| `site.profile` | 你的个人主页链接（结构化数据用） |
| `site.ogImage` | 默认分享图文件名（放 `public/` 下） |
| `posts.perPage` / `perIndex` | 列表每页 / 首页最近文章条数 |
| `features` | 亮暗模式、归档页、返回按钮、搜索等开关 |
| `socials` | 底部社交入口（GitHub / Email） |
| `shareLinks` | 文章页“分享到”入口 |

> 发布前请把所有标了 **`[FILL_ME]`** 的字段替换成你自己的真实信息
>（URL / 标题 / 作者 / GitHub / Email 等），本仓库没有虚构任何个人信息。

## 🎨 调整外观

- **配色 / 字体**：`src/styles/theme.css`（亮/暗两套 `--background/foreground/accent/...` 变量）
- **正文排版**：`src/styles/typography.css`
- **图标**：`src/assets/icons/`、`src/assets/icons/socials/`
- **favicon**：`public/favicon.svg`

设计原则：克制、安静、文字优先。别引入大型 UI 框架或大量客户端 JS，
保持静态站的高速加载。

## 📁 目录速览

```
/
├── astro-paper.config.ts     # ★ 唯一需要常改的配置文件
├── src/
│   ├── content/posts/        # ★ 文章，Markdown 放这里
│   ├── content/pages/about.md

│   ├── layouts/              # 页面骨架
│   ├── pages/                # 路由（首页/文章/标签/关于/搜索…）
│   ├── i18n/                 # 界面文案（已是中文）
│   └── styles/               # 主题与排版
└── public/                   # 静态资源（favicon、分享图、…）
```
