Agent 的上层是规划，底层是运行时。这篇是一份阅读笔记。

## 运行时负责什么

一个 Agent 运行时大致要处理几件杂事：

- **事件循环**：把模型输出、工具结果串成一个可推进的循环。
- **工具调用**：把计划里的动作解析出来，映射到真实函数。
- **状态管理**：上下文、会话、执行痕迹，跨步骤保持一致。
- **安全边界**：权限控制、超时、资源限制。

## 为什么"运行时"值得单独拆出来

因为计划和执行是两件事。把运行时和策略分离，好处是：

1. 换模型不用重写执行逻辑。
2. 工具的权限与校验集中在同一层。
3. 更容易做日志、追踪和回放。

## 一个小收获

很多"神奇"的能力，拆开看都是朴素的循环 + 良好的抽象。往下读源码，比看一百篇介绍都有用。
