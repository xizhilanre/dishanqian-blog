AI Agent 最近被说了很多，很多是概念。我在这里只记录我自己的理解。

## 工具是单向的

传统软件是一问一答，用户给指令，程序给结果。工具本身没有"意图"，也不会自己往前走。

## Agent 是目标导向的

Agent 更像一个协作者：给它一个目标，它能把一个大任务拆成小步骤，中间调用工具、验证结果、失败重试，直到完成。

也许不需要把它想得太玄，Agent 的本质是一层"会计划、会执行、会反思"的循环：

1. 理解目标
2. 制定计划
3. 调用工具执行
4. 检查结果
5. 必要时修正计划

这既是能力，也是成本：一个能自主行动的循环，也需要被更好地约束和观察。

## 该警惕什么

- **过度信任**：Agent 的每一步都不一定对，输出不可信时需要校验。
- **失控风险**：自主动作越多，越需要权限边界。
- **别为了 Agent 而 Agent**：很多任务其实一个函数就够了。
